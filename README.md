# Nitesh Patel — Web Developer

Portfolio, selected projects, services, writing, and web development briefs.

## Build

Run `python3 build.py` to regenerate the static site in `dist/`. The committed `dist/` directory is deployed by Vercel. Update the `origin` constant in `build.py` if the production domain changes, then rebuild.

## Deployment

This repository contains a prebuilt static export. Vercel serves `dist/` using `vercel.json`. No credentials or external runtime services are required.
